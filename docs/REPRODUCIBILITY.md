# Reproducibility - Module 2

## Environment used for the reported results

| Item | Value |
|---|---|
| OS | Windows 11 Pro (10.0.26200) |
| CPU | Intel Core i7-10610U, 4 cores / 8 threads; no GPU needed |
| Python | 3.12.10 |
| Packages | exact pins in `requirements.txt` (no PyTorch needed) |
| Seed | 42 for every model, the split and NSGA-II |

## Exact commands

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt

python -m src.download_data          # ~10 MB: patch Parquet (Hugging Face) + Mendeley XLSX, SHA-256 checked
python -m src.preprocessing          # targets, cleaning, data dictionary, split checked against data/splits
python -m src.numerical_model        # surrogates, parity / importance plots, engineering summaries
python -m src.fusion_optimization    # fusion with Module 1 embeddings + NSGA-II for n78
pytest -q                            # 10 tests
python scripts/make_deliverables.py  # block diagram, poster, slides, Word/LaTeX report
```

`scripts/run_all.ps1` (Windows) and `scripts/run_all.sh` (bash) run the whole pipeline. The full pipeline takes a few minutes on a laptop CPU.
To refresh the report's table of contents and export the PDF (Windows + Microsoft Word):
`powershell -File scripts\docx_to_pdf.ps1 reports\module2_report.docx`.

## Inputs from Module 1

`data/external/module1_vit_embeddings/` holds the 384-d CLS embeddings exported by Module 1
(`results/features/vit_finetune_patch_perf_class_s42_*.npy` in that repository) with their SHA-256 hashes in `provenance.json`.
Module 2 needs nothing else from Module 1; the split manifests in `data/splits/` are the same locked files.

## Determinism

Preprocessing, the split and the surrogates are deterministic given the seed. Repeated NSGA-II runs can differ slightly because parallel
random-forest prediction and the evolutionary operators interact with thread scheduling (for example, Pareto area ranges starting at
296–304 mm² across runs). The deliverables always read the metrics files of the run that produced them.

## Artefacts not stored in Git

Raw downloads (`data/raw/`) and fitted surrogate models (`results/checkpoints/`); both are regenerated by the scripts.
