What this demo is

This page is the interactive companion to the Module 2 report Numerical-Text Surrogate Modelling and Multi-Objective Optimisation of Compact Patch Antennas. It runs entirely in your browser. The trained random-forest surrogates were evaluated ahead of time on a dense grid (161 lengths × 25 W/L ratios × 21 feed positions = 84,525 designs). The explorer snaps your slider settings to that grid, so the numbers match what the Python model returns. S11 curves are shown at 200 points (the lowest value in each 5-point bin, so resonance dips are kept).

Data

  • Rectangular Patch Antenna Frequency Response, 2,051 openEMS designs, MIT licence (LaBash et al., 2025, arXiv:2505.18188).
  • Antenna Parameters Dataset v2, Mendeley Data, doi:10.17632/3gxr2vvd9n.2, CC BY 4.0.

Limits

The simulations come from openEMS, not Ansys HFSS, and no design here was fabricated or measured. Accuracy drops sharply outside the training range (see Model performance). Use the outputs for screening and teaching, not for sign-off.

Rebuild the data with python scripts/make_demo.py. Source: docs/demo.
